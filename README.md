## 项目简介

**叙事剧场**是一个单文件 HTML 应用，把"AI 角色扮演"和"图形化关系编辑器"结合在一起：

- 左侧面板管理 **世界观**、**角色**、**全局设置** 三大模块；
- 右侧聊天区进行 AI 对话推进；
- 内置 **D3.js 力导向关系图**，可视化角色关系并支持点击编辑；
- 基于 **导演 + 演员 + 旁白** 三段式提示词驱动剧情。

无需后端、无需构建工具，打开浏览器即可使用。

## 功能特性

### 🎭 角色系统
- 每个角色包含：姓名、性格、背景、说话倾向（1–10）、当前情绪（1–上限）、情绪上限（1–10）。
- 支持 **连续发言上限** 计算：`maxConsecutive = max(1, floor(0.5 * √(情绪 × 倾向)))`，防止单一角色刷屏。
- 角色可动态增删改，删除时同步清理相关关系。

### 🕸️ 关系图编辑器
- 点击「🎭 角色设定」模块打开全屏图形编辑器。
- 基于 D3.js 力导向布局，支持节点拖拽、缩放平移。
- **点击连线自动填充**到左侧关系编辑栏，修改后一键保存。
- 双向关系自动分离绘制（避免重叠），箭头指示方向。
- 悬浮节点/连线时信息栏实时显示详情。

### 🤖 三种对话推进方式
| 模式 | 说明 |
|------|------|
| **手动扮演** | 选择角色 → AI 生成该角色的动作与台词 |
| **AI 自动推进** | 导演模型调整情绪、推荐最佳/次佳发言角色，自动生成回复 |
| **用户扮演** | 用户选择角色并输入动作+台词，直接写入对话历史 |

此外还提供 **📖 生成剧情旁白**，让 AI 以"剧本推进者"身份输出一句情节推进。

### ⏪ 消息回溯与重生成
- 每条消息悬浮时显示操作按钮（鼠标移入消息区域）。
- **🔄 重新生成**：调用 AI 重写该条消息。
- **⏪ 回溯至此**：恢复该消息时刻的角色/关系/场景快照，并删除其后所有对话。
- 快照采用深拷贝，回溯不会污染当前状态。

### 🎨 主题与外观
- 深色 / 浅色双模式切换。
- 自定义 **强调色**、**背景渐变起止色**（通过 `<input type="color">`）。
- 毛玻璃卡片、圆角气泡、渐变背景等现代 UI 设计。

### 💾 存档系统
- 一键 **导出存档** 为 JSON（实际下载为 `.txt`）。
- 支持 **导入存档**，自动补齐缺失字段（如 `maxExcitement`、`continuousCount`）。
- 存档包含：角色、关系、场景、动机、完整对话历史（含快照）。

### 🎲 NPC 临时角色
- 导演模型可在必要时生成 **临时 NPC** 发言，以 `[NPC] 名字` 形式呈现，使用不同气泡样式。

## 快速开始

1. **下载或保存** 本文件为 `叙事剧场.html`。
2. 确认同目录下存在 **D3.js v7**（文件内引用路径为 `./叙事剧场 · Ver.1.0_files/d3.v7.min.js.download`）。如缺失，可改为 CDN：
   ```html
   <script src="https://d3js.org/d3.v7.min.js"></script>
   ```
3. 用浏览器（建议 Chrome / Edge / Firefox 最新版）打开。
4. 点击右上角 **⚙️ 全局设置**，填入 API Key。
5. 点击「🎭 角色设定」编辑角色与关系，点击「🌍 世界观设定」填写场景与动机。
6. 开始对话：手动扮演 / AI 自动推进 / 用户发言。

> 首次打开会自动载入一个示例剧本（角色：樱、凛、良；场景：创咖）。

## 使用说明

### 界面布局

```
┌────────────────────┬─────────────────────────────┐
│  🌍 世界观设定      │  🎬 叙事剧场 · AI 对话       │
│  🎭 角色设定        │  ┌───────────────────────┐  │
│   （含缩略关系图）   │  │  消息气泡区域          │  │
│  ⚙️ 全局设置        │  └───────────────────────┘  │
│                    │  [角色选择][动作][台词][按钮] │
└────────────────────┴─────────────────────────────┘
```

### 角色情绪与发言机制

1. **导演阶段**（AI 自动推进时触发）：
   - 读取最近 12 条对话；
   - 输出 JSON：`new_excitements`（新情绪值）、`best_next`（最佳发言者）、`alternate_next`（备选）、`npc`（可选临时 NPC）；
   - 若模型输出非 JSON，会尝试用正则提取 `{...}` 块，仍失败则回退到权重排序。

2. **发言阶段**：
   - 演员提示词严格限定输出 `{"action": "...", "content": "..."}`；
   - 连续发言超限时自动切换到备选角色（并给出系统提示）。

3. **情绪权重公式**：`talkativeness × excitement` 越高越可能被选中。

### 关系编辑流程

1. 点击「🎭 角色设定」→ 打开关系图编辑器；
2. 左侧可新增角色、修改选中角色属性、设置双向关系；
3. 右侧图形中**点击连线**可将该关系回填至左侧表单；
4. 修改后点「保存关系」，图与预览同步刷新。

### 回溯与重生成

- 将鼠标移到某条消息气泡上，右侧出现操作按钮；
- **重新生成** 仅对真实角色消息可用（NPC / 系统消息不可重生成）；
- **回溯** 会恢复该条消息的 `snapshot`（角色属性、关系、场景、动机）并截断后续历史。

## API 配置

### 默认配置

```js
const API_URL = "https://models.sjtu.edu.cn/api/v1/chat/completions";
let apiKey = "";            // 在「全局设置」中填写
let modelName = "deepseek-chat";
let corsProxy = "";         // 可选，CORS 代理前缀
```

### 使用其他 OpenAI 兼容服务

1. 在「全局设置」中修改 **模型名称**；
2. 若需更换接口地址，可修改代码中的 `API_URL` 常量；
3. 若目标接口存在 CORS 限制，可设置 `corsProxy`（如 `https://your-proxy.example.com`），请求会自动拼接为 `corsProxy/原始URL`。

### 请求参数

- `temperature`：导演 0.5 / 演员 0.7 / 旁白 0.7
- `max_tokens`：导演 400 / 演员 220 / 旁白 100
- `top_p`: 0.9
- 超时：30 秒（`AbortController`）

## 存档格式

导出的 JSON 结构如下：

```json
{
  "roles": [
    {
      "id": "1699999999999-abcde",
      "name": "樱",
      "personality": "阳光元气",
      "background": "大三女生",
      "talkativeness": 10,
      "excitement": 5,
      "maxExcitement": 8,
      "continuousCount": 0
    }
  ],
  "roleRelations": {
    "樱": { "良": "两人互为舍友" },
    "良": { "樱": "两人互为舍友", "凛": "良是凛的社团前辈。" }
  },
  "relationText": "",
  "scene": "在创咖。下午四点左右，店内比较安静。",
  "motivation": "凛和良一起来到创咖，偶遇正在喝咖啡的樱。",
  "chatHistory": [
    {
      "roleName": "system",
      "content": "对话已重置。",
      "action": "",
      "timestamp": 1699999999999,
      "snapshot": { "...": "该时刻的完整状态快照" },
      "rawResponse": null,
      "rawRoleplayResponse": null,
      "isNPC": false
    }
  ]
}
```

**导入兼容性**：若角色缺少 `maxExcitement` 或 `continuousCount`，会自动补默认值（10 / 0）。

## 注意事项

### ⚠️ 数据持久化
- 应用 **不使用 localStorage**，刷新页面后当前进度会丢失；
- 请定期使用「全局设置 → 导出存档」保存进度；
- 导入存档会**覆盖**当前全部状态。

### ⚠️ API Key 安全
- API Key 仅保存在内存中，不会写入存档文件；
- 请勿在公共设备上填写真实 Key；
- 导出存档时不包含 Key，无需担心泄露。

### ⚠️ 模型输出稳定性
- 导演与演员均要求严格 JSON 输出，但模型可能返回多余文本；
- 代码已内置正则提取兜底，仍失败时会回退到权重排序或提示错误；
- 若频繁失败，可尝试更换模型或降低 `temperature`。

### ⚠️ 浏览器兼容性
- 依赖 `backdrop-filter`、CSS 变量、ES6+，建议使用现代浏览器；
- 移动端布局已做基础适配（viewport + flex 换行），但关系图编辑器体验以大屏为佳。

### ⚠️ D3.js 依赖
- 文件头部引用路径为本地相对路径，若 D3 缺失将导致关系图无法渲染；
- 建议改用 CDN（见「快速开始」）以确保可用。

### 💡 调试技巧
- 浏览器控制台可访问全局变量 `roles`、`chatHistory`、`scene` 等；
- 消息对象中保留 `rawResponse` / `rawRoleplayResponse`，便于排查模型原始输出；
- 快照 (`snapshot`) 是回溯的核心，回溯异常时优先检查该字段是否存在。
